# 家族の調子

質問に答えるのではなく、**タップのリズムと反応速度**から心と体の状態を数値化し、
家族で「信号(🟢🟡🔴)+トレンド(↗→↘)」として共有するWebアプリです。

## なぜ質問形式ではないのか

自己申告のアンケートは、本人の意図とは関係なく遠慮や誇張が入ります。
このアプリは**パフォーマンス測定**なので、意識して良く見せることが困難です。

## 測定内容(1回およそ60秒)

| ステップ | 測ること | 拾える状態 |
|---|---|---|
| ① 10秒静止 | 手の震え | 緊張・自律神経・疲労 |
| ② 10秒タップ | タップ数 | 体のキレ・活動性 |
| ② 10秒タップ | リズムのばらつき | 心の安定・集中 |
| ③ 反応テスト(10回) | 処理の速さ(逆数RT) | 頭の冴え・疲労 |
| ③ 反応テスト(10回) | ばらつき・見落とし | 集中の途切れ |

### なぜ静止テストが最初なのか

連打の直後は手が震えるため、タップより先に測る必要があります。

生理的な微細な震えは**意識で抑えることができません**。画面にゆれを表示して
「できるだけ動かさないで」と促すことで、本人の限界(＝実力)を測る形にしており、
**「調子が良いふり」が原理的にできない**指標になっています。

動きセンサーが無い端末や、利用を許可しなかった場合は、この項目だけ自動的に
スキップされ、残りの指標で採点します。

「体のキレ」はタップ数と処理の速さ、「心の余裕」はリズム・反応のばらつきと
見落としから算出します。指標数が違っても偏らないよう、2つの軸を均して合成します。

### 精度のための工夫

- **逆数RT(1000/RT の平均)** を速さの指標に使用。PVT研究で疲労・睡眠不足に
  もっとも敏感とされる指標で、極端に遅い1回に振り回されにくい
- **反応テストは10回**。5回では「ばらつき」の推定が不安定になる
- **100ms未満の反応は当て推量として除外**(標準的なPVTと同様)
- **平常値は中央値+MAD** で算出。1日だけの外れ値でばらつきが膨らみ、
  その後の判定が鈍る問題を回避
- **測定時刻を記録**。反応速度は時間帯で大きく動くため、普段と3時間以上
  ずれた測定は「参考値」と明示して体調の変化と混同しないようにする
- **判定の確かさ**(学習日数)を表示
- 震えは**3軸それぞれを高域通過してから合成**。合成の大きさだけを見ると、
  重力と直交する方向の震え(手の震えの主成分)が重力に埋もれて検出できない

## スコアの考え方

他人とは比較しません。**その人自身の過去3週間の平常値からのズレ**で採点します。

- 🟢 いつも通り
- 🟡 少しお疲れ気味かも
- 🔴 かなり無理してるサイン

信号が出るまで最低4回の測定が必要です(平常値の学習のため)。
学習が10日を超えると精度が上がり、注意書きが消えます。
毎朝など**同じ時間帯**で測ると精度が上がります。

## 使い方

`index.html` をブラウザで開くだけです。ビルド不要・依存ライブラリなし。

初回は右上の ⚙︎ →「デモデータを入れて動きを見る」で完成イメージを確認できます。

## 家族で共有する設定(Firebase)

設定しなくてもアプリは「この端末のみ」モードで動きます。
家族全員の調子を1つの画面で見たい場合は、以下を一度だけ設定してください。

### 1. Firebase プロジェクトを作る

1. https://console.firebase.google.com/ を開き「プロジェクトを追加」
2. 名前は何でもよい(例: `kazoku-choshi`)。Google Analytics は**不要**
3. 左メニュー「構築」→「Realtime Database」→「データベースを作成」
4. ロケーションは asia-southeast1 など。**「ロックモードで開始」**を選ぶ

### 2. セキュリティルールを設定する

Realtime Database の「ルール」タブに、以下を貼り付けて「公開」:

```json
{
  "rules": {
    "families": {
      "$code": {
        ".read": "$code.length >= 16",
        ".write": "$code.length >= 16"
      }
    }
  }
}
```

合言葉(18文字のランダム文字列)を知っている人だけが読み書きできます。
合言葉の一覧を取得することはできないため、総当たりで探すことは事実上不可能です。

### 3. 設定を config.js に貼り付ける

「プロジェクトの設定(⚙)」→「マイアプリ」→ ウェブ `</>` を追加 → 表示される
`firebaseConfig` の中身を `config.js` にコピーします。

> Firebase のウェブ用 apiKey は公開前提の識別子であり、秘密鍵ではありません。
> 実際の保護は上記のルールと合言葉が担っています。

### 4. 使い方

1. 誰か1人が ⚙︎ →「家族グループを作る」→ 合言葉が発行される
2. その合言葉を家族に送る
3. 家族は各自 ⚙︎ →「合言葉で参加する」に貼り付ける

以降、全員の測定結果が自動で同期されます。

## データの保存先

- 共有を設定していない場合: 各端末のブラウザ内(localStorage)のみ
- 共有を設定した場合: 自分の Firebase プロジェクト内のみ

記録は**この GitHub リポジトリには一切保存されません**。
記録は人ごと・日付ごとに個別保存されるため、家族が同時に測定しても互いの記録を
上書きしません。通信できないときはローカルに保存され、オフラインでも測定できます。

## 注意

体調の目安を見るためのアプリであり、医療的な診断ではありません。
