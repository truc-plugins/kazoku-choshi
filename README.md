# 家族の調子

質問に答えるのではなく、**タップのリズムと反応速度**から心と体の状態を数値化し、
家族で「信号(🟢🟡🔴)+トレンド(↗→↘)」として共有するWebアプリです。

## なぜ質問形式ではないのか

自己申告のアンケートは、本人の意図とは関係なく遠慮や誇張が入ります。
このアプリは**パフォーマンス測定**なので、意識して良く見せることが困難です。

## 測定内容(1回およそ40秒)

| ステップ | 測ること | 拾える状態 |
|---|---|---|
| ① 10秒タップ | タップ数 | 体のキレ・活動性 |
| ① 10秒タップ | リズムのばらつき | 心の安定・集中 |
| ② 反応テスト(5回) | 反応の速さ(中央値) | 頭の冴え・疲労 |
| ② 反応テスト(5回) | ばらつき・見落とし | 集中の途切れ |

## スコアの考え方

他人とは比較しません。**その人自身の過去2週間の平常値からのズレ**で採点します。

- 🟢 いつも通り
- 🟡 少しお疲れ気味かも
- 🔴 かなり無理してるサイン

信号が出るまで最低3回の測定が必要です(平常値の学習のため)。
毎朝など条件をそろえて測ると精度が上がります。

## 使い方

`index.html` をブラウザで開くだけです。ビルド不要・依存ライブラリなし。

初回は右上の ⚙︎ →「デモデータを入れて動きを見る」で完成イメージを確認できます。

## データの保存先

記録は各端末のブラウザ内(localStorage)にのみ保存されます。
このリポジトリにも、外部サーバーにも、個人のデータは一切送信されません。

## 注意

体調の目安を見るためのアプリであり、医療的な診断ではありません。
